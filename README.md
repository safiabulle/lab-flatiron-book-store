# Flatbooks Technical Books (DOM Project)
## AUTHOR - SAFIA BULLE

## Description
This project is a simple DOM manipulation exercise that displays a list of books from a JavaScript object. It dynamically updates the webpage by changing the store title and generating book elements (title, author, and image) without reloading the page.

## Installation

### Steps
1. Clone the repository:
git clone git@github.com:safiabulle/lab-flatiron-book-store.git
2. Navigate into the project folder:
cd lab-flatiron-book-store
3. Open the project in VS Code:
code .
Open index.html in your browser.

### Usage 

The project runs automatically in the browser.

JavaScript will:

- Update the store title dynamically
- Loop through the books array
- Create and display book cards
- Append them to the DOM
- Remove an element with id delete-this (if it exists)

### Features
Dynamic DOM manipulation
Object-based data rendering
Automatic book list generation
Image rendering for each book
Clean and reusable JavaScript logic
Bonus: Element removal from DOM
